# Elementor Template Json Importer

Client-side tool: load an Elementor template JSON + a Word (.docx) content doc, auto-match content to every text field (headings, text editors, accordions, tabs, icon boxes, buttons...), review/adjust, then export a new template JSON to import back into Elementor.

## Use
Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages > Deploy from branch `main` / root).

## Push to GitHub
```
git remote add origin https://github.com/<your-username>/elementor-template-json-importer.git
git push -u origin main
```
