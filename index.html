1. Add your Elementor template

The .json file exported from Elementor.

2. Add your content document

A Word file using Heading 1/2/3. Text is inserted as plain text by default. Each section can keep its HTML formatting instead. Meta lines (META TITLE, META DESCRIPTION, SLUG) and [ADD …] placeholders are ignored.

3. Check the page

Drag blocks from your document (left) onto the fields of the page (right). Each bullet in a list can be dragged on its own into an icon-list row, or drop a whole list on a row to fill the rows from there down. You can also drag between fields, or drag a field back to the left to unplace it. On touch screens: tap a field, then tap a block.
